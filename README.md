Entry for the [make.fun bounty "Everyday Things, Two Lines, Longer Run"](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) ($2).

`main.py` is deterministic — no network, no randomness — and writes one
two-line explanation to `/output/entry.txt`: line 1 explains a toaster to a
10-year-old in a single vivid sentence built on one analogy, and line 2 says
in one sentence what that analogy maps and what it leaves out.

Run it with:

```sh
python3 main.py
```
